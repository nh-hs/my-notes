## 二、经典面试题

拼多列用join表，拼多行用union表

如果列名是中文，那么取列的值列名要用反引号括起来

### 1. 多行转多列（多行转一行）

```sql
# 思想：
# 第一列：分组
select number
from area.score
group by number;
# 第二列：查询成绩，判断，聚合
select number                         '学号',
       sum(if(kemu = '语文', score, 0)) '语文',
       sum(if(kemu = '数学', score, 0)) '数学',
       sum(if(kemu = '英语', score, 0)) '英语'
from area.score
group by number;


#思想：先拼接，后筛选 （性能很低）
select s1.number '学号', s1.score '语文', s2.score '数学', s3.score '英语'
from area.score s1
       join area.score s2 on s1.number = s2.number
       join area.score s3 on s1.number = s3.number
where s1.kemu = '语文'
  and s2.kemu = '数学'
  and s3.kemu = '英语';
# 思想：拼接时筛选（性能低）
select s1.number '学号', s1.score '语文', s2.score '数学', s3.score '英语'
from area.score s1
       join area.score s2 on s1.number = s2.number and s1.kemu = '语文' and s2.kemu = '数学'
       join area.score s3 on s1.number = s3.number and s3.kemu = '英语';
```

### 2. 多列转多行（一行转多行）

```sql
# 思想：凑学号，科目，成绩（三个），再用union拼接,再排序
select number '学号', '语文' as '科目', yuwen '成绩'
from area.info
union
select number, '数学' as '科目', shuxue '成绩'
from area.info
union
select number, '英语' as '科目', yingyu '成绩'
from area.info
order by 学号;  # 排序
```
