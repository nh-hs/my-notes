## 三、闭包

- 闭包核心：绕过垃圾回收机制的一种高级编程思想
- 闭包三要素：
  1. 外部函数函数嵌套内部函数（有嵌套）
  2.  函数内部引用外部函数的变量（有引用） 关键字nonlocal
  3. 返回内部函数名（不能有括号）（有返回）

```python
# 使用闭包实现累计计数
def outer_fn():
    count = 0

    # 有嵌套
    def inner_fn():
        # 有引用
        nonlocal count
        count += 1
        print(f'当前的count为{count}')

    # 有返回
    return inner_fn


# 接受返回值
fn = outer_fn()
# 调用
fn()
```

## 五、装饰器的分类

### 1. 无参无返回值

```python
import time
# 定义统计用时装饰器
def check_time(fn):
    # 有嵌套
    def inner_fn():
        # 函数执行前时间
        start = time.time()
        # 有调用（外部函数形参）
        fn()
        # 函数执行后时间
        end = time.time()
        # 打印执行时间按
        print('函数执行时间：%f' % (end - start))
    # 返回内部函数名
    return inner_fn
# 手搓
def work():
    a = 1
    b = 2
    print(a + b)
    time.sleep(2)
1.通过check装饰work,构造一个新的fn
new_work = check_time(work)
2.新的fn调用才能实现效果
new_work()
# 语法糖
@check_time
def work():
    a = 1
    b = 2
    print(a + b)
    time.sleep(2)
# 调用
work()
```

### 3. 无参有返回值

### 5. 通用装饰器

```python
# 通用装饰器模板
def check_time(fn):
    # 有嵌套
    def inner_fn(*args, **kwargs):
        # -------------------------装饰器功能【先执行装饰器功能】
        print('功能')
        # -------------------------装饰器功能【先执行装饰器功能】
        # 有调用（外部函数形参）
        res = fn(*args, **kwargs)
        # -------------------------装饰器功能【后执行装饰器功能】
        print('功能')
        # -------------------------装饰器功能【后执行装饰器功能】
        return res

    # 返回内部函数名
    return inner_fn

@check_time
def work(*args, **kwargs):
    num_sum = 0
    # 求元组args的和
    for i in args:
        num_sum += i
    # 求字典kwargs的和
    for i in kwargs:
        num_sum += kwargs[i]
    print(f'和为{num_sum}')
    
# 补充：
# 原则：关键字不定长写在位置不定长后面
# 原则：位置参数写在默认值参数前面
```

## 六、装饰器的其他使用

### 1. 多装饰器的使用

效果：装饰器执行顺序按照从上往下逐个执行

原理：装饰的顺序从下到上，把装饰器加函数当作一个新函数

```python
# 登录
def login(fn):
    def inner_fn(*args, **kwargs):
        print('请先登录')
        res = fn(*args, **kwargs)
        return res
    return inner_fn
# 评论
def comment(fn):
    def inner_fn(*args, **kwargs):
        print('发布评论')
        res = fn(*args, **kwargs)
        return res
    return inner_fn
# 点赞
@login
@comment
def like():
    print('点赞')
```

### 2. 装饰器的参数

装饰器如果有参数，需要在原来的装饰器的基础上再包裹一层进行接收

```python
def flag(flag):
    def param_calc(fn):
        def inner_fn(*arg, **kwargs):
            res = fn(*arg, **kwargs)
            if flag == '+':
                print('装饰器加法执行完成~')
            else:
                print('装饰器减法执行完成~')
            return res
        return inner_fn
    return param_calc
@flag('+')
def calc1(a, b):
    print(a + b)
@flag('-')
def calc2(a, b):
    print(a - b)
# 调用
calc1(1, 2)
calc2(1, 2)
```
