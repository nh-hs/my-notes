## 三、容器

### 1. 字符串容器

**字符串是一个不可修改的只读容器**

#### 1.1 取出数据

```python
# 取指定的某个数据[索引/小标]，索引从0开始
# 语法：容器[索引]

# 取指定的某些数据 - 切片
# 语法：容器[开始索引：结束索引：步长] 包头不包尾
```

#### 1.2 索引

```python
# 正索引：从左往右，从0开始
# 负索引：从右往左，从-1开始
# 切片也能使用负索引
# 步长也可以使用负步长（从右往左切），步长默认是1
# 如果是到头，可以省略索引
# 字符串反转：字符串名称[::-1]
```

#### 1.3 字符串常用方法

```python
# 获取字符串长度 len(字符串)

# 检测字符串是否包含某段内容，统计出现的次数  
# 字符串名称.count(要查找的内容)

# 字符串的替换（不会改变原内容，而是生成新内容） 
# 字符串名称.replace(旧内容，新内容)

# 取出字符串两端的空格 字符串名称.strip()
# 去除前后两端指定字符串 字符串名称.strip(要去除的内容)

# 字符串切分（切完后是一个列表） 
# 字符串名称.split(以什么分)

# 获取某个字符第一次出现的索引（没有就报错）  
# 字符串名称.index(要获取索引的字符)
```

### 2. 列表容器

#### 2.1定义列表

```python
# 语法：
# 变量名 = [内容1,内容2,内容3,......]
# 空列表：
# 变量名 = []
# 变量名 = list()
```

#### 2.2 列表常用方法

list.append() 是直接修改原列表，并且它会返回 None，Python 中大多数修改列表的方法都是这样的

~~~python
list_a = [1, 2, 3]
list_b = list_a.append(4)

print(list_a)  # [1, 2, 3, 4]  ← 原列表被修改了
print(list_b)  # None           ←  append() 返回的是 None

# 如果想要一个包含新元素的新列表（不修改原列表）：
list_b = list_a + [4]      # list_a 保持不变
~~~
