## 四、数据类型转换

~~~python
type()  # 查看类型
int()   # 转整数
float() # 转浮点数
str()   # 转字符串
bool()  # 转布尔值

# 注：所有类型都可以转字符串和布尔类型
# 注：只有值是数字才可以转数字
# 注：转布尔类型大多数为True，表示为空值时才会转False
~~~

## 五、标识符命名的规范

### 1. 标识符

- 变量标识符 - 变量名
- 函数标识符 - 函数名
- 类标识符 - 类名

### 2. 命名规则

1. 命名的限制：数字（不能为开头）、字母、下划线、中文（不建议）
2. 严格区分大小写
3. 不能使用关键字

### 3. 命名规范

1. 见名知意
2. 全小写英文单词
3. 多个单词用下划线链接，过长用缩写

## 七、字符串用法

### 1. 定义字符串

- '字符串'
- "字符串"
- """字符串"""（多行定义）

### 2. 格式化字符串

1. 百分号格式化

   ~~~python
   # 语法： ‘xxxx%sxx%dxxx%fxxx’ %(变量1，变量2，变量3)
   ~~~

   注：小数的格式化

   ~~~python
   # 控制整数宽度(了解)
   %4d
   %2.1f
   # 控制小数精度(保留两位小数)
   %.2f
   ~~~

2. format格式化

   ~~~python
   'xx{}xxxx，xx{}，xx{}，xx{}'.format(变量1, 变量2, 变量3, 变量4)
   ~~~

3. format简写格式化（重点）

   ~~~python
   f'xx{变量1}xxxx，xx{变量2}，xx{变量3}，xx{变量4:.2f}' #变量4保留两位小数
   f"xx{变量1}xxxx，xx{变量2}，xx{变量3}，xx{变量4:.2f}"
   f"""xx{变量1}xxxx，xx{变量2}，xx{变量3}，xx{变量4:.2f}"""
   ~~~
