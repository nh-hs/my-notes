## 三、魔法方法

魔法方法 - 在某种情况下自动执行的方法

注：+ - * / in 等关键字都是魔法方法的变体

### 1. \_\_init\_\_

```python
# __init__  -  创建对象时自动执行
# 给__init__传递参数是在创造对象时写在类（）里面的

# 示例：
# 创造明星类  差异属性:名字，唱的歌
class Star():
    def __init__(self, name, song):
        self.name = name
        self.song = song

    def show(self):
        print(f'{self.name}正在唱{self.song}')


# 实例化对象
star1 = Star('刘德华', '恭喜发财')
star2 = Star('蔡徐坤', '鸡你太美')
# 调用方法
star1.show()
star2.show()
```

## 四、面向对象案列（ATM）

```python
# 需求：登录，查询，存钱，取钱，退出
# 创建类
class Atm():
    # 定义属性
    def __init__(self, account, password):
        self.account = account
        self.password = password
        self.money = 0

    # 定义方法
    # 登录
    def login(self):
        account = input('请输入用户名：')
        password = int(input('请输入密码：'))
        if account == self.account and password == self.password:
            print('登陆成功')
            self.start()
        else:
            print('账户或密码错误，请重新输入')

    # 查询
    def search_money(self):
        print(f'当前的余额为：{self.money}')

    # 存钱
    def save_money(self):
        save = int(input('请输入存钱金额：'))
        self.money += save
        print('已存钱')

    # 取钱
    def get_money(self):
        get = int(input('请输入取钱金额：'))
        self.money -= get
        print('已取钱')

    # 开始
    def start(self):
        while True:
            num = input("""
            请选择要办理的业务：
            1.查询
            2.取钱
            3.存钱
            4.退出
            """)
            if num == '1':
                self.search_money()
            elif num == '2':
                self.get_money()
            elif num == '3':
                self.save_money()
            elif num == '4':
                break


# 对象
bank = Atm('zzbn', 123456)
bank.login()
```

### 5. super

1. **如果子类没有定义自己的 `__init__`**，会自动继承父类的 `__init__`
2. **如果子类定义了自己的 `__init__`**，会覆盖父类的 `__init__`，此时需要手动调用父类的 `__init__`

`super()` 用于调用父类（超类）的方法，最常见的就是在子类的 `__init__` 中调用父类的 `__init__`。

```python
class Parent:
    def __init__(self, name, age):
        self.name = name
        self.age = age

class Child(Parent):
    def __init__(self, name, age, school):
        super().__init__(name, age)  # 调用父类的 __init__
        self.school = school

c = Child("小明", 12, "第一小学")
print(c.name, c.age, c.school)  # 小明 12 第一小学
```
