## matplotlib

>步骤：
>
>1. 导包
>
>   a. import matplotlib
>
>   b. import matplotlib.pyplot as plt
>
>2. 默认设置（引擎：TkAgg，中文支持）
>
>   a. 引擎：matplotlib.use('TkAgg')
>
>   b. 中文支持：matplotlib.rcParams['font.sans-serif'] = ['SimHei']
>
>3. 设置画板大小
>
>   plt.figure(figsize=(xx, xx))
>
>4. 绘制数据
>
>   plt.plot
>
>   a. plot 折线图
>
>   b. scatter 散点图
>
>   c. bar 柱状图
>
>   d. pie 饼图
>
>5. 其他配置
>
>   a. x轴y轴说明  plt.xlabei()  plt.ylabel
>
>   b. 网格  plt.grid()
>
>   c. 标题  plt.title()
>
>   d. 展示标签  plt.legend()
>
>6. 展示绘制结果
>
>   plt.show()

~~~python
# 案例：
import matplotlib
import matplotlib.pyplot as plt
import pandas as pd

matplotlib.use('TkAgg')
matplotlib.rcParams['font.sans-serif'] = ['SimHei']

plt.figure(figsize=(10, 7))
# 读取csv文件获取数据
df = pd.read_csv('1960-2019全球GDP数据.csv', sep=',', encoding='gbk')

# 数据预处理
# 查看是否有空
print(df.isnull().sum())
# 删除空行
df.dropna(inplace=True)
# 提取要绘制的数据
df_us = df[df['country'] == '美国']
df_cn = df[df['country'] == '中国']
df_jp = df[df['country'] == '日本']
# 把年分设置为索引，压缩数据量
df_us.set_index('year', inplace=True)
df_cn.set_index('year', inplace=True)
df_jp.set_index('year', inplace=True)
# 数据的绘制
# 绘制数据
plt.plot(df_us.index, df_us['GDP'], label='美国', color='blue', linewidth='2')
plt.plot(df_cn.index, df_cn['GDP'], label='中国', color='red', linewidth='2')
plt.plot(df_jp.index, df_jp['GDP'], label='日本', color='green', linewidth='2')
# 图例补充
plt.legend()
plt.xlabel('年份',)
plt.ylabel('GDP')
plt.title('1960-2019全球GDP数据')
plt.grid()
plt.show()
~~~

## linux操作指令

### 常用基础命令

#### 四大基础命令

>clear：清屏  快捷键CTRL+L
>
>ls：展示当前目录下所有文件
>
>​	-a:展示出隐藏文件
>
>​	-l:以详细信息展示文件
>
>​	-h:配合-l使用，人性化展示文件大小
>
>​	一般常用ll
>
>cd：切换到目录位置
>
>pwd：打印当前所在位置的绝对路径
>
>补充：
>
>绝对路径：以**根目录/**为起点描述路径的方式
>
>相对路径：以**当前目录**为起点描述路径的方式
>
>.表示当前目录
>
>..表示上一级目录

#### 帮助/手册

>命令 --help：列举命令的帮助文档
>
>man 命令：查看命令详细手册

#### 文件创建与删除

>1. 创建
>
>   1. mkdir [-p] 目录路径：创建指定**目录**
>
>      -p：可选，表示自动创建不存在的父目录，适用于连续创建多层级目录
>
>   2. touch 文件路径：创建指定**文件**
>
>2. 删除
>
>1. rm [-r -f] 要删除的文件夹或者文件：删除指定的文件或文件夹
>   1. -r：删除文件夹
>    2. -f：强制删除文件或文件夹
>2. 注：rm -rf 不要随便用

#### 文件查看

>1. cat [-n] 文件：查看文件内容（一般用于小文件）
>
>   -n ：显示行号
>
>2. more [-num]：查看文件内容（一般用于大文件，可以翻页）
>
>   空格：下一页
>
>   b：上一页
>
>   q：退出
>
>   -num：展示的条数
>
>3. head [-num] 文件路径：查看文件头部几行
>
>   默认前10行
>
>   -num：指定行数
>
>4. tail [-num] 文件路径：查看文件尾部几行
>
>   默认后10行
>
>   -num：指定行数

#### 移动和复制

>1. 移动
>
>   mv 要移动的文件或文件夹 目标位置：移动指定文件或文件夹到指定位置
>
>   注：目标位置是文件（文件夹），文件（文件夹）不存在就会直接改名
>
>2. 复制
>
>   cp [-r] 要复制的文件或文件夹 目标位置：复制文件或文件夹到指定位置
>
>   ​	-r：主要用于复制文件夹
>
>   ​	cp复制文件后，源文件依旧存在

#### 打印与重定向

> 1. echo：默认打印到控制台
>
> 2. 重定向命令：
>
>    \>:覆盖写入
>
>    \>\>:追加写入
>
> 3. echo 经常与重定向命令搭配使用
>
>    echo hello >> h.txt

#### 打包解包

> 1. 打包：
>
>    1. 普通打包格式：tar -cvf 包名.tar 多个文件或目录
>    2. gzip压缩格式：tar -zcvf 包名.tar.gz 多个文件或目录
>
> 2. 解包：
>
>    1. 普通解包格式：tar -xvf 包名.tar -C 目标位置路径
>    2. gzip压缩格式：tar -zxvf 包名.tar.gz -C 目标位置路径
>
> 3. 参数：
>
>    -c，创建压缩文件，用于压缩模式
>
>    -v，显示压缩、解压过程，用于查看进度
>
>    -x，解压模式
>
>    -f，要创建的文件，或要解压的文件，-f选项必须在所有选项中位置处于最后一个
>
>    -z，gzip模式，不使用-z就是普通的tarball格式
>
>    -C，选择解压的目的地，用于解压模式
