核心：防止代码报错影响后续代码的执行

```python
# try 			（尝试执行的代码）
# except Exception as e		（代码出错时执行）
# else 			（代码没出错时执行（埋点））
# finally		（无论出没出错都要执行）

# 提炼：try + except
```

### 1. 文件操作

~~~python

# 关闭

~~~

### 2. 文件读写模式

- file

  ```python
  # 绝对路径 （一般用于读取服务器上的内容）
  # 相对路径 上一级../    下一级/
  ```

- mode

  ```python
  # r读取文件，光标在起始位置，不能创建文件   w写入文件，光标在起始位置，可以创建文件（会覆盖）   a追加文件，光标在结束模式   b二进制流   +补充模式
  # w+    写读文件
  # wb+   二进制的方式读写文件
  # r+    读写文件
  # rb    二进制的方式读取文件
  # rb+   二进制的方式读写文件
  # wb    二进制的方式写入文件
  # a+    追加文件（没有就创建文件）
  # ab    二进制的方式追加文件
  # ab+   二进制的方式追加创建文件
  ```

- encoding

  - utf-8		万国码
  - gbk           中文编码

## 四、包与模块

### 1. 模块

```python
# from （从哪里） import （导入）
# import （导入）
# 模块名 == 文件名
# 1. import 模块
# 2. import 模块 as 别名
# 3. form 模块 import 内容1，内容2
# 4. form 模块 import * （所有内容）
# 5. form 模块 import 内容1 as 别名

# 注：调用时定义模块就模块.方法名，定义方法就直接用方法名
# 注：方法调用时就近查找导入方法名
# 注：导入模块时会把模块执行一次
"""
__name__当前文件运行的文件名
如果是在当前文件运行就是__main__
如果是被调用时运行就是__name__所在文件名
所以测试模块时加上if __name__ == '__main__':(main + 回车)
"""
```
