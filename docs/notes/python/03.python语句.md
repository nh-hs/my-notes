### 1. 单分支

```python

```

### 2. 双分支

```python
# 语法：
# if 条件：
#     如果条件成立时执行
# else：
#     如果条件不成立时执行
```

### 3. 多分支

#### 3.3 含else

```python
"""
语法1：有else
if 条件1：
    条件1成立时执行的代码
elif 条件2：
    条件2成立时执行的代码
......
elif 条件n：
    条件n成立时执行的代码
else：
    所有条件都不成立时执行的代码
"""
```

#### 3.2 不含else

```python
"""
语法2：
if 条件1：
    条件1成立时执行的代码
elif 条件2：
    条件2成立时执行的代码
......
elif 条件n：
    条件n成立时执行的代码
"""
```

### 1. while循环

#### 1.1 死循环

```python

#     条件成立时执行的代码
```

#### 1.2 循环

```python
# 语法
# 初始变量
# while 条件:
#     要循环的代码
#     修改初始变量

# 循环的三要素：
#   1.定义变量(while循环前就要定义) - 记录循环次数
#   2.结束条件 - 终止循环
#   3.修改变量 - 更新循环次数
```

#### 1.3 循环嵌套

```python
# and 与
# 一假全假，全真为真，碰到假的才停，否则取最后一个真的
print('to be' and 'not to be')  # not to be

# or 或
# 一真全真，全假为假，碰到真的才停，否则取最后一个假的
print(False or '')   # 输出为空

# not 非
```
