# 无代码搭建智能聊天机器人

## 一、环境介绍

### 1. 前端

- cmd - 执行ollama的指令

- apifox - 讲解前后端如何进行通信

  http请求真正组成部分：

  http://(协议)   127.0.0.1(域名（ip）)  :  11434(端口)

- chatbox - 真正智能聊天机器人的前端界面

### 2. 后端

#### 2.1 ollama - 指令

客户端命令：

1. 查看当前本地模型有哪些

   ollama list

2. 拉取服务器模型

   ollama pull 模型名称：参数

3. 运行模型（如果没有模型，会先拉取再运行）

   ollama run 模型名称：参数

4. 复制模型

   ollama cp 要复制的模型名称：复制后的模型名称

5. 删除模型

   ollama rm 要删除的模型名称

6. 查看运行的模型（1. 要有运行的模型 2. 新建窗口才能查看）

   ollama ps

7. 查看模型信息

   ollama show 模型名称

对话指令：

1. 聊天指令

   正常文本输入

2. 多行输入

   """ 多行输入内容1

   多行输入内容2

   多行输入内容3

   """

3. 清空之前的聊天会话记录（不是清空聊天窗口文字，而是让模型忘记之前聊天记录）

   /clear

4. 切换模型（不忘记之前聊天内容，重新换一个模型接着回复）

   /load 要切换的模型

5. 结束对话

   /bye    （快捷键：ctrl + d  或者直接关闭cmd窗口）
